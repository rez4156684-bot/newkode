## 📖 توضیحات | Description

افزونه حرفه‌ای نمایش تگ تخفیف روی محصولات ووکامرس با پنل تنظیمات کامل، اشکال متنوع و کنترل جداگانه برای هر محصول.

Professional discount tag plugin for WooCommerce with complete settings panel, various shapes, and per-product control.

## 🚀 نصب | Installation

### روش 1: نصب دستی | Manual Installation

1. فایل `woocommerce-discount-tag-pro.php` را دانلود کنید
2. فایل را در مسیر `/wp-content/plugins/` آپلود کنید
3. به **افزونه‌ها > افزونه‌های نصب شده** بروید
4. افزونه **WooCommerce Discount Tag Pro** را فعال کنید

### روش 2: آپلود از پنل | Upload via Admin Panel

1. فایل را در یک فایل ZIP قرار دهید
2. به **افزونه‌ها > افزودن** بروید
3. روی **آپلود افزونه** کلیک کنید
4. فایل ZIP را انتخاب و نصب کنید
5. افزونه را فعال کنید

## ⚙️ راهنمای تنظیمات | Settings Guide

### 1️⃣ تنظیمات عمومی

پس از فعال‌سازی افزونه:

1. به **ووکامرس > تنظیمات** بروید
2. تب **تگ تخفیف** را انتخاب کنید
3. تنظیمات زیر را تنظیم کنید:

#### 🔹 فعال‌سازی
- تیک بزنید تا افزونه فعال شود
- برای غیرفعال کردن موقت، تیک را بردارید

#### 🔹 متن تگ
- متن پیش‌فرض: `تخفیف لحظه آخری`
- می‌توانید هر متنی بنویسید:
  - `فروش ویژه`
  - `تخفیف فوق‌العاده`
  - `حراج`
  - و غیره...

#### 🔹 شکل تگ
6 شکل مختلف برای انتخاب:
- **مربع (Badge)**: مناسب برای همه موارد
- **دایره (Circle)**: برای طراحی مدرن
- **روبان (Ribbon)**: برای جلب توجه بیشتر
- **گوشه (Corner)**: برای استفاده بهینه از فضا
- **ستاره (Star)**: برای تخفیف‌های ویژه
- **شش‌ضلعی (Hexagon)**: برای ظاهر حرفه‌ای

#### 🔹 موقعیت تگ
5 موقعیت مختلف:
- **بالا راست** (پیشنهادی برای فارسی)
- **بالا چپ**
- **پایین راست**
- **پایین چپ**
- **وسط تصویر**

#### 🔹 رنگ‌ها
- **رنگ پس‌زمینه**: انتخاب از پالت رنگ
  - پیش‌فرض: قرمز (#ff0000)
  - پیشنهادات: قرمز، نارنجی، سبز، آبی
- **رنگ متن**: پیش‌فرض سفید (#ffffff)

#### 🔹 اندازه فونت
- محدوده: 8 تا 30 پیکسل
- پیش‌فرض: 12 پیکسل
- پیشنهاد: 10-14 برای موبایل

#### 🔹 نمایش درصد تخفیف
- **فعال**: درصد تخفیف محاسبه و نمایش داده می‌شود
- **غیرفعال**: فقط متن نمایش داده می‌شود

#### 🔹 انیمیشن
- **فعال/غیرفعال**: کنترل نمایش انیمیشن
- **نوع انیمیشن**: انتخاب از 5 نوع مختلف
  - Pulse: ضربان ملایم
  - Bounce: پرش بالا و پایین
  - Shake: لرزش چپ و راست
  - Rotate: چرخش ملایم
  - Glow: درخشش رنگی

#### 🔹 محل نمایش
- **نمایش در فروشگاه**: صفحه اصلی فروشگاه و دسته‌بندی‌ها
- **نمایش در صفحه محصول**: صفحه جزئیات محصول

---

### 2️⃣ تنظیمات محصول جداگانه

برای تنظیم تگ تخفیف برای هر محصول:

1. به **محصولات** بروید
2. محصول مورد نظر را **ویرایش** کنید
3. در سمت راست، باکس **تنظیمات تگ تخفیف** را پیدا کنید

#### گزینه‌های موجود:

##### 🔹 غیرفعال کردن تگ
- تیک بزنید تا تگ تخفیف برای این محصول نمایش داده نشود
- مفید برای محصولاتی که نمی‌خواهید تگ داشته باشند

##### 🔹 متن سفارشی
- متن اختصاصی برای این محصول
- در صورت خالی بودن، متن پیش‌فرض استفاده می‌شود
- مثال‌ها:
  - `پیشنهاد ویژه`
  - `آخرین فرصت`
  - `محصول ویژه`

## 🔧 سفارشی‌سازی پیشرفته | Advanced Customization

### تغییر استایل با CSS

می‌توانید با افزودن CSS سفارشی، ظاهر تگ را بیشتر تغییر دهید:

```css
/* تغییر سایه تگ */
.wc-discount-tag-pro .discount-badge {
    box-shadow: 0 5px 15px rgba(0, 0, 0, 0.5);
}

/* اضافه کردن حاشیه */
.wc-discount-tag-pro .discount-badge {
    border: 3px solid #ffffff;
}

/* تغییر فونت */
.wc-discount-tag-pro .discount-text {
    font-family: 'Vazir', 'Tahoma', sans-serif;
}
```

## ❓ سوالات متداول | FAQ

### چگونه تگ را فقط برای محصولات خاص نمایش دهم؟
به صفحه ویرایش محصول بروید و در باکس "تنظیمات تگ تخفیف" تنظیمات دلخواه را انجام دهید.

### آیا می‌توانم چند رنگ مختلف برای محصولات مختلف داشته باشم؟
در نسخه فعلی، یک رنگ عمومی وجود دارد. اما می‌توانید با CSS سفارشی این کار را انجام دهید.

### تگ در تم من نمایش داده نمی‌شود!
- مطمئن شوید افزونه فعال است
- بررسی کنید که محصول در حال تخفیف باشد
- تنظیمات "نمایش در فروشگاه" و "نمایش در صفحه محصول" را چک کنید
- بررسی کنید تگ برای آن محصول خاص غیرفعال نشده باشد

### آیا با تمام تم‌ها سازگار است؟
بله، افزونه از هوک‌های استاندارد ووکامرس استفاده می‌کند و با اکثر تم‌ها سازگار است.

### چگونه انیمیشن را غیرفعال کنم؟
در تنظیمات افزونه، تیک "فعال‌سازی انیمیشن" را بردارید.
