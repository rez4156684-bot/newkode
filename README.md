## 📖 توضیحات | Description

این افزونه به صورت خودکار تگ "تخفیف لحظه آخری" را روی تصاویر محصولات تخفیف‌دار ووکامرس نمایش می‌دهد.

This plugin automatically displays a "Last Minute Discount" tag on WooCommerce sale products.

- ✅ نمایش خودکار تگ تخفیف روی محصولات در حال تخفیف
- ✅ نمایش درصد تخفیف
- ✅ انیمیشن جذاب و چشم‌نواز
- ✅ طراحی ریسپانسیو
- ✅ سازگار با تم‌های مختلف وردپرس
- ✅ پشتیبانی از زبان فارسی و راست به چپ (RTL)
- ✅ بدون نیاز به تنظیمات پیچیده
- ✅ سبک و بهینه

## 🚀 نصب | Installation

### روش 1: نصب دستی | Manual Installation

1. فایل‌های افزونه را در پوشه `/wp-content/plugins/woocommerce-discount-tag/` آپلود کنید
2. به پنل مدیریت وردپرس بروید
3. از منوی افزونه‌ها (Plugins) افزونه را فعال کنید

### روش 2: آپلود از پنل مدیریت | Upload via Admin Panel

1. فایل‌ها را در یک فایل ZIP قرار دهید
2. به Plugins > Add New بروید
3. روی Upload Plugin کلیک کنید
4. فایل ZIP را آپلود و نصب کنید
5. افزونه را فعال کنید

## 🎨 نحوه استفاده | Usage

پس از فعال‌سازی افزونه، تگ تخفیف به صورت خودکار روی تمام محصولات تخفیف‌دار نمایش داده می‌شود:

- **صفحه فروشگاه**: تگ در گوشه راست بالای تصویر محصول ظاهر می‌شود
- **صفحه محصول**: تگ با اندازه بزرگتر روی گالری تصاویر نمایش داده می‌شود

---

After activation, the discount tag will automatically appear on all sale products:

- **Shop page**: Tag appears in the top-right corner of product images
- **Product page**: Larger tag displays on the image gallery

## 🎨 سفارشی‌سازی | Customization

می‌توانید استایل‌های CSS را در فایل `assets/css/discount-tag.css` ویرایش کنید تا ظاهر تگ را سفارشی کنید.

You can edit the CSS styles in `assets/css/discount-tag.css` to customize the tag appearance.

### مثال‌های سفارشی‌سازی | Customization Examples:

```css
/* تغییر رنگ تگ | Change tag color */
.wc-discount-tag .discount-badge {
    background: linear-gradient(135deg, #00ff00 0%, #00cc00 100%);
}

/* تغییر اندازه فونت | Change font size */
.wc-discount-tag .discount-text {
    font-size: 14px;
}

/* تغییر موقعیت | Change position */
.wc-discount-tag {
    top: 20px;
    right: 20px;
}
```
